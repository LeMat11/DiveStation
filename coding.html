推荐开场话术

“我先确认一下：输入是否已经按时间排序？重复序号应该保留第一条还是最后一条？空输入返回空列表。暴力做法是 O(n²)，我可以用一个字典/双指针做到 O(n)；我先讲一下 invariant 再写。”

只需要熟练的 8 个模式

足够覆盖大部分初中级 Coding Test

Hash map / set

查重、计数、按 ID 找回、补数。典型复杂度 O(n) 时间、O(n) 空间。

Two pointers

两个有序流合并、从两端收缩、原地去重。关键是每步至少移动一个指针。

Sliding window

连续时间段的和、均值、最大/最短满足条件。明确窗口 [l, r] 的 invariant。

Stack / queue

嵌套结构、最近 N 项、BFS、生产者消费者。有界性比容器名字更重要。

Binary search

有序数据找位置，或对单调可行性搜索答案。先固定一种边界模板。

State machine

状态 + 事件 + 显式转换。动作与转换分开，非法事件行为可预测。

Prefix / running state

累计和、运行最值、上一次状态。流式数据常只需 O(1) 状态。

BFS / graph basics

无权最短步数、多源距离、依赖关系。用 visited 保证每个节点只处理一次。

练习题

草稿和完成状态只保存在当前浏览器

CORE 01EasyHash map

Two Sum：补数查找

建议 15 分钟

给定整数数组 nums 和目标值 target，返回两个不同元素的索引，使它们之和等于 target。保证恰好有一个答案。

展开思路、边界与参考实现
识别信号

找一对元素满足精确和；未排序；目标 O(n)。站在当前 x 上，需要找的是 target - x。

Invariant

seen 只保存当前位置之前出现过的值到索引的映射，因此不会重复使用同一元素。

替代思路

暴力双循环 O(n²)；排序 + 双指针 O(n log n)，但必须保留原索引。

常见错误

先插入再检查会让元素与自己匹配；重复数字如 [3,3] 是必测边界。

def two_sum(nums, target):
    seen = {}
    for i, x in enumerate(nums):
        need = target - x
        if need in seen:
            return [seen[need], i]
        seen[x] = i
    return []

# Time O(n), space O(n)
CORE 02EasySet / protocol

控制包去重：保留每个序号的第一包

建议 15 分钟

输入按到达顺序排列的包 [(seq, command), ...]。网络可能重复投递；返回去重后的列表，保留每个 seq 第一次出现的包，并保持原到达顺序。

展开思路、协议语义与参考实现
主解

用 set 记录已经接受的 seq；第一次出现才 append。稳定去重是一遍扫描。

复杂度

平均 O(n) 时间，O(u) 空间，u 为唯一序号数。

协议延伸

真实序号可能回绕，不能让 set 永久增长；常用滑动窗口/最大已确认序号和模运算。

先问清

重复 seq 但 command 不同是保留第一条、最后一条还是报协议错误？题目指定第一条。

def dedupe_packets(packets):
    seen = set()
    out = []
    for seq, command in packets:
        if seq in seen:
            continue
        seen.add(seq)
        out.append((seq, command))
    return out

# Time O(n), space O(u)
CORE 03EasyRunning state

按钮上升沿：按住只触发一次

建议 12 分钟

给定每个控制周期采样的布尔列表，例如 [False, True, True, False, True]，返回发生 0→1 上升沿的索引。

展开思路、状态机联系与参考实现
Invariant

prev 始终代表前一个采样；当前为 True 且 prev 为 False 才触发。

边界

第一个样本为 True 是否算按下？通常以初始未按下 False 为基准，因此算。

工程延伸

机械按钮还需要 debounce；网络按键还要处理丢包和长时间冻结。

项目联系

巡航切换、E-Stop reset、录制开关都不应在 50 Hz 按住时重复触发。

def rising_edges(samples):
    out = []
    prev = False
    for i, current in enumerate(samples):
        if current and not prev:
            out.append(i)
        prev = current
    return out

# Time O(n), extra space O(1) excluding output
CORE 04EasySliding window

传感器滑动平均

建议 18 分钟

给定数值列表和窗口大小 k，返回每个长度为 k 的连续窗口平均值。若 k 无效抛出 ValueError。

展开思路、数值边界与参考实现
主解

先求第一个窗口和，之后每步加新值、减旧值；避免每个窗口重新 sum。

复杂度

O(n) 时间；除输出外 O(1) 空间。

边界

k ≤ 0、k > n；k = 1；空数组。返回 [] 还是异常必须先约定。

控制提醒

移动平均引入约 (k−1)/2 个采样的群延迟；不能只谈降噪，不谈相位。

def moving_average(values, k):
    if k <= 0 or k > len(values):
        raise ValueError("invalid window size")
    total = sum(values[:k])
    out = [total / k]
    for right in range(k, len(values)):
        total += values[right] - values[right - k]
        out.append(total / k)
    return out

# Time O(n), extra space O(1)
CORE 05Light MediumQueue / design

有界遥测 Ring Buffer

建议 25 分钟

实现 RingBuffer(capacity)，支持 append(x) 和 items()；只保留最近 capacity 项，并按从旧到新返回。capacity 必须为正。

展开思路、替代方案与参考实现
最实用主解

Python 直接使用 collections.deque(maxlen=capacity)，标准库已正确实现淘汰。

手写版本

固定数组 + next write index + size；返回时从最老位置绕回。面试官若要求底层再写。

复杂度

append 均摊 O(1)；items O(k)，k 为当前长度；内存 O(capacity)。

并发边界

deque 的单次操作不等于复合读取是事务；跨线程一致快照仍需锁或单写者设计。

from collections import deque

class RingBuffer:
    def __init__(self, capacity):
        if capacity <= 0:
            raise ValueError("capacity must be positive")
        self._data = deque(maxlen=capacity)

    def append(self, value):
        self._data.append(value)

    def items(self):
        return list(self._data)

# append O(1), items O(k), memory O(capacity)
CORE 06Light MediumBinary search

标定表线性插值

建议 25 分钟

table 是按 raw 升序排列的 [(raw, value), ...]。给定 x，在相邻点间线性插值；超出范围时 clamp 到端点。

展开思路、二分边界与参考实现
主解

先 clamp，再用 bisect_right 找第一个大于 x 的位置 hi，lo = hi - 1。

Invariant

经过 clamp 后一定有 raw[lo] ≤ x < raw[hi]，因此分母不应为零。

复杂度

若 raw 列表预先缓存，单次查询 O(log n)；现场每次提取 raws 会额外 O(n)。

工程边界

表内 raw 必须严格递增；外推通常比 clamp 风险大；标定 interpolation 不等于验证 accuracy。

from bisect import bisect_right

def calibration_lookup(table, x):
    if not table:
        raise ValueError("empty table")
    if x <= table[0][0]:
        return table[0][1]
    if x >= table[-1][0]:
        return table[-1][1]

    raws = [raw for raw, _ in table]
    hi = bisect_right(raws, x)
    r0, v0 = table[hi - 1]
    r1, v1 = table[hi]
    t = (x - r0) / (r1 - r0)
    return v0 + t * (v1 - v0)

# Query O(log n) after raws are cached
CORE 07Light MediumTwo pointers

合并两个有序事件流

建议 22 分钟

两个列表 a 和 b 都由 (timestamp, source, value) 构成并按 timestamp 升序。返回稳定合并后的单一时间线；时间相同时 a 中的事件在前。

展开思路、同步联系与参考实现
主解

两个指针比较当前时间戳，取较小者；相等时用 ≤ 保证 a 在前。最后追加剩余尾部。

Invariant

out 始终有序；a[:i] 与 b[:j] 已全部放入，剩余元素不可能比 out 最后更早。

复杂度

O(n+m) 时间；输出 O(n+m)。直接 concat + sort 是 O((n+m)log(n+m))。

机器人联系

合并不等于时间同步。不同设备时钟必须先映射到共同时间基，之后才能按 timestamp 合并。

def merge_events(a, b):
    i = j = 0
    out = []
    while i < len(a) and j < len(b):
        if a[i][0] <= b[j][0]:
            out.append(a[i])
            i += 1
        else:
            out.append(b[j])
            j += 1
    out.extend(a[i:])
    out.extend(b[j:])
    return out

# Time O(n + m), output space O(n + m)
CORE 08Light MediumState / safety

Watchdog：判断最新有效命令

建议 25 分钟

包为 (seq, timestamp, command)。给定到达顺序的 packets、当前单调时间 now 和 timeout，返回“序号严格递增且未超时”的最后一条有效 command；否则返回 "STOP"。忽略旧序号和未来时间戳。

展开思路、安全语义与参考实现
拆条件

序号比上次接受的大；时间不在未来；最后接受包的 age ≤ timeout。值存在不代表值新鲜。

复杂度

一遍扫描 O(n)，O(1) 额外空间。

先问清

序号是否会回绕？timestamp 与 now 是否同一单调时钟？超时边界用 < 还是 ≤？

安全延伸

STOP 是示意；真实系统还需 armed latch、明确恢复流程和执行器级独立保护。

def latest_safe_command(packets, now, timeout):
    best_seq = None
    best_time = None
    best_command = None

    for seq, timestamp, command in packets:
        if timestamp > now:
            continue
        if best_seq is None or seq > best_seq:
            best_seq = seq
            best_time = timestamp
            best_command = command

    if best_time is None or now - best_time > timeout:
        return "STOP"
    return best_command

# Time O(n), extra space O(1)
OPTIONAL 09EasyCounting

最高频故障码 Top K

建议 18 分钟

给定故障码列表和 k，返回出现次数最多的 k 个故障码；次数相同时按故障码字典序升序。

展开思路、确定性排序与参考实现
主解

字典计数，再按 (-count, code) 排序，取前 k。

为什么加 tie-break

确定性输出让测试、日志和 UI 稳定；“任意顺序”与生产代码要求不同。

升级

大量唯一元素且 k 很小时用 heap O(u log k)；在线流可用近似 heavy-hitter。

复杂度

简单版本 O(n + u log u)，空间 O(u)。

def top_k_faults(codes, k):
    counts = {}
    for code in codes:
        counts[code] = counts.get(code, 0) + 1
    ordered = sorted(counts, key=lambda c: (-counts[c], c))
    return ordered[:k]
OPTIONAL 10Light MediumMulti-source BFS

障碍物距离场

建议 30 分钟

网格中 1 为障碍、0 为自由。返回每个格子到最近障碍的四连通步数；保证至少一个障碍。

展开思路、为什么是多源 BFS 与参考实现
关键转化

不是从每个空格做 BFS，而是把所有障碍同时作为距离 0 的起点，一次向外扩散。

Invariant

BFS 首次到达某格时，路径步数最短；dist = -1 同时充当未访问标志。

复杂度

每格最多入队一次，O(RC) 时间和 O(RC) 空间。

常见坑

[[-1] * cols] * rows 会让所有行引用同一列表；必须列表推导。

from collections import deque

def obstacle_distance(grid):
    rows, cols = len(grid), len(grid[0])
    dist = [[-1] * cols for _ in range(rows)]
    q = deque()
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == 1:
                dist[r][c] = 0
                q.append((r, c))

    while q:
        r, c = q.popleft()
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < rows and 0 <= nc < cols and dist[nr][nc] == -1:
                dist[nr][nc] = dist[r][c] + 1
                q.append((nr, nc))
    return dist
OPTIONAL 11Light MediumState machine

控制权仲裁状态机

建议 30 分钟

实现 next_state(state, event)。状态：DISARMED、MANUAL、CRUISE、ESTOP。事件：ARM、DISARM、LOCK、OVERRIDE、ESTOP、RESET。ESTOP 从任何状态进入；只有 ESTOP + RESET 回到 DISARMED；非法组合保持原状态。

展开思路、优先级与参考实现
先处理全局高优先级

ESTOP 事件覆盖所有普通转换；当前 ESTOP 时只接受 RESET。

转换表优点

合法转换是数据，容易审查和单元测试；比层层 if/else 更不容易漏。

测试策略

枚举所有 state × event，检查 ESTOP invariant、RESET 边界和非法事件幂等。

真实系统

状态转换和 entry/exit action 应分离；恢复前还需硬件安全条件和显式 re-arm。

def next_state(state, event):
    if event == "ESTOP":
        return "ESTOP"
    if state == "ESTOP":
        return "DISARMED" if event == "RESET" else "ESTOP"

    transitions = {
        ("DISARMED", "ARM"): "MANUAL",
        ("MANUAL", "LOCK"): "CRUISE",
        ("CRUISE", "OVERRIDE"): "MANUAL",
        ("MANUAL", "DISARM"): "DISARMED",
        ("CRUISE", "DISARM"): "DISARMED",
    }
    return transitions.get((state, event), state)
OPTIONAL 12DebugPython

为什么函数“记住了”上一次数据？

建议 12 分钟

下面函数连续调用会共享同一个列表。解释根因并修复：def add_sample(x, samples=[]): samples.append(x); return samples。

展开根因、正确修复与相关陷阱
根因

默认参数在函数定义时求值一次，不是每次调用重新创建；可变列表因此跨调用共享。

修复

使用 None sentinel，在函数体内创建新列表。若本来就需要累积，应显式放到对象状态里。

相邻陷阱

二维数组别写 [[0]*m]*n；dataclass 可变字段用 default_factory。

测试

连续两次不传 samples 调用，第二次结果必须只包含第二个值。

def add_sample(x, samples=None):
    if samples is None:
        samples = []
    samples.append(x)
    return samples
