90 秒项目陈述

目标 → 核心判断 → 三段证据 → 结果 → 边界

我的 CLD 项目研究的是软体水下机器人在快速加速时，怎样不用额外传感器和主动刚度控制，也能适应不断变化的流体载荷。传统方法常围绕共振或主动调刚度，但加速时前进速度、附加质量和流体阻尼每个周期都在变，很难一直维持窄带共振。我提出用约束层阻尼结构，让黏弹芯层在更高频率下产生更多剪切耗散，从而主要提高损耗分量、基本保持储能刚度，并被动改变力与运动的相位关系。

我设计并制造了 PLA / 亚克力泡沫 / PET 对称夹层推进器，先做 0–5 Hz 干态弯曲阻抗测试，再在水洞中对四种 CLD 覆盖率、St = 0.2–0.8 做约束推进和相位分辨 PIV，最后用 3 kg 虚拟质量完成一维非约束加速验证。在 St = 0.8 时，66.7% 覆盖率方案把平均推力从 0.16 N 提升到 0.51 N，峰值加速度从 0.039 提升到 0.191 m/s²，终端速度从 0.105 提升到 0.291 m/s。PIV 显示它形成了更连贯的 LEV/TEV，并抑制了高频寄生弯曲。

这个工作的贡献是把相位导向的被动阻抗整形作为软体推进设计原则。它目前只在单自由度和一维虚拟质量条件下验证，真实自由游动、多自由度 CLD 分布以及覆盖率优化仍是后续工作。

必须讲清的力学与流体机理

公式不只要会写，还要说假设、测量方法和物理意义

K*(ω) = K′(ω) + iK″(ω)

K′ 是与角位移同相的储能分量；K″ 是相差 90° 的耗散分量。项目中的核心观察是：0–5 Hz 内 K′ 近似不变，而 K″ 随频率上升。

K*(ω) = T̂(ω) / θ̂(ω)

从单频角度与扭矩的复幅值求比值。锁相/谐波回归只提取目标基频，能降低噪声和高次谐波对相位估计的干扰。

为什么不是“简单加硬”？

如果主要增加弹性刚度，阻抗各分量会近似一起缩放，组成比例和相位不会呈现论文观察到的频率演化。CLD 的关键是黏弹芯层被约束层迫使产生剪切，使增长集中在损耗分量。

为什么相位比共振更关键？

加速过程中前进速度、约化频率、附加质量和流体阻尼不断变化，窄带共振难以维持；瞬时推进更直接受力与推进器速度的相位对齐和每周期净冲量控制。

“机械低通滤波”是什么？

更高的损耗模量会耗散高频寄生模态，使尾缘轨迹从方波样畸变回到更平滑的近正弦运动。这是结构动力学意义的滤波，不是数字滤波器。

为什么相位滞后反而有益？

在刚性传动里延迟常意味着响应损失；这里适量结构滞后让软鳍在换向时更平滑地让位于流体，减少突兀分离，促进 LEV 附着和更有序的涡脱落。不能泛化成“延迟越多越好”。

高概率项目追问

先自己口答 60–120 秒，再展开核对

01为什么加速工况下不能只追求共振？必会

回答主线

共振峰窄且依赖系统参数。加速时前进速度不断变化，流体附加质量、阻尼、约化频率与耦合边界条件随周期变化，系统会快速离开原来的共振点。即便维持振幅共振，也不等于每周期净推力冲量最大；瞬态推进更看重流体力与推进器速度的相位关系。

追问防守

不要否定共振对稳态巡航的价值。你的论点是“瞬态快速加速的主导设计目标不同”，不是“共振永远没用”。

02CLD 为什么能主要提高损耗分量，而不显著改变储能刚度？必会

弯曲时外侧 PET 约束层限制黏弹芯层的自由伸缩，使宏观弯曲转化为芯层剪切。亚克力泡沫是率相关材料，剪切应力和每周期耗散随频率上升；基体 PLA 主导低频弹性刚度，所以测试范围内 K′ 近似稳定、K″ 单调增长。对称铺层也降低了静态翘曲和非目标弯扭耦合。

03你怎样从角度和扭矩数据里提取 K′、K″？为什么不用峰值比？必会

对每个单频工况，将 θ(t) 与 T(t) 回归到同频正余弦基底，得到复幅值 θ̂ 与 T̂，再计算 K* = T̂/θ̂，实部和虚部分别对应储能与损耗。单纯峰值比只给幅值，丢失相位；直接找峰值还容易受噪声、高次谐波和采样离散影响。锁相提取能把目标基频与其他频率成分分离。

04Strouhal 数在你的实验里怎么定义？0.2–0.8 是怎样得到的？必会

采用 St = fA/U，其中 A 是峰–峰尾迹/驱动幅值约定时必须说明。本实验 heave 为 ±0.04 m，因此峰–峰幅值 A = 0.08 m，U = 0.2 m/s，f = 0.5–2 Hz，对应 St = 0.2–0.8。面试时要主动交代幅值定义，否则只写公式会产生一倍因子歧义。

05为什么 CLD 在低 St 推力差异小，而高 St 差异迅速扩大？必会

CLD 的黏弹损耗是率相关的：低频时 K″ 较小，四种构型的有效动力学接近；频率升高后芯层剪切耗散增加，覆盖率更高的构型对相位和寄生模态的调节更明显。与此同时高 St 流体载荷更强，结构阻抗不匹配造成的相位问题被放大，因此性能差异出现非线性扩张。

06PIV 具体给了什么证据？你如何避免过度解释？必会

在 0.5π 附近，design c 显示更大且连贯的附着 LEV、较流向的 TEV，对应平滑高推力峰；在 1.1π 换向附近，它保持更好的弦向涡量连续性并更早形成新半周期 LEV。baseline 的涡结构较弱、偏转或快速弥散。PIV 支持相位/涡结构机制，但只是中展向二维平面、有限相位与工况，不能单独证明完整三维因果。

07为什么设计四种覆盖率，而不是只对比 baseline 和最高覆盖？高频

中间覆盖率能判断效果是否随 CLD 用量呈连续趋势，减少“两个样品偶然差异”的解释空间，并初步观察是否存在阈值或饱和。当前只有 0%、16.7%、33.3%、66.7% 四级，足以支持单调趋势，但不能证明最优覆盖率，更不能解析弦向/展向分布和厚度的交互作用。

08为什么虚拟质量是 3 kg？这种验证的价值和局限分别是什么？高频

3 kg 用来近似同尺度典型机器人质量，并让测得推力实时驱动可控的一维动态模型。价值是保持同一执行平台和测力链，直接检验推力能否转化为加速度；局限是没有真实本体的附加质量随姿态变化、横向/航向动力学、推进器–机身干扰和六自由度稳定性。它比固定测力更接近任务层，但不是物理自由游动。

09实验里有哪些主要误差源？你会怎样做不确定度分析？高频
  • ATI 零漂、结构惯性力和安装偏差；应做静态归零、空载/惯性基线与坐标变换。
  • 层压厚度、气泡、粘结与覆盖位置差异；应记录制造公差并增加独立样品重复。
  • 频率/相位同步和初始瞬态；应丢弃启动周期，用统一时钟做相位平均。
  • PIV 的标定、粒子密度、窗口尺寸和面外速度；应报告 vector validation 和空间分辨率。
  • 现在论文报告同一条件三次重复的标准差；若要更强结论，应区分 trial repeatability 与 specimen-to-specimen variability。
10为什么高阻尼没有必然降低推进效率？高频

阻尼本身耗能，但系统效率取决于输入能量有多少形成有用轴向动量，而不是材料耗散单项越低越好。baseline 在高 St 下出现相位失配、寄生高频形变和无效侧向流动；适量耗散虽然损失部分结构能量，却改善了力时序与涡结构，使有用推力不再快速崩塌。结果也不是 design c 全程效率最高：低 St baseline 峰值约 20%，design c 更像维持约 10% 平台，在高 St 才显示优势。

11如果要把 CLD 做到真实机器人上，你首先补哪三项验证？系统题
  1. 物理自由游动：包含机身、浮力、附加质量和六自由度稳定性的水下试验。
  2. 耐久与环境：吸水、温度、盐水、循环疲劳、粘结老化对 K′/K″ 的影响。
  3. 可制造优化：覆盖位置、厚度、层向、质量与效率的多目标设计，并对多个样品做统计重复。

之后才是多关节/分布式 CLD 与控制协同。

12RL 为什么选 SAC，而不是 DDPG、PPO 或 CPG？RL

动作是连续的频率和幅值，SAC 的 off-policy replay 提高样本利用率，熵正则鼓励探索，并通常比 DDPG 对超参数和噪声更稳。PPO 可用但 on-policy 样本成本更高。CPG 是一种动作生成先验，不等于学习算法；当前设计刻意让策略直接选择两个高层周期参数，先检验 CLD 是否压缩搜索空间。最终选择仍需同预算基线实验支持，不能把经验偏好说成已证明最优。

13你如何验证“CLD 提高 sim-to-real 鲁棒性”这个假设？RL

先固定训练预算和策略结构，对 CLD 与刚性/纯弹性基线分别训练；在评估阶段系统扰动阻力系数、附加质量、传感噪声、动作延迟和结构参数，例如水动力参数 ±30%，比较回报下降率、成功率和策略频率调度变化。再把相同策略接口转到实验硬件，比较零样本和少量校准后的性能。需要多随机种子和置信区间；当前这些仍是实验计划。

14MuJoCo 里怎样表示频率相关 K(f)/B(f)？最大风险是什么？RL

可从材料/结构测试建立 K、B 随频率的查表或平滑拟合，在每个控制段根据当前动作频率更新等效关节刚度与阻尼。风险是把线性单频、稳态识别出的参数直接用于大振幅、非平稳、多关节水中运动：频率估计可能滞后，材料有幅值/温度依赖，关节间耦合也被忽略。因此要做参数边界、插值连续性、能量合理性检查，并用硬件扫频逐层标定。

15如果面试官质疑“损耗变大为什么叫阻抗整形，而不是阻尼器”，你怎么回答？表达

“阻尼器”描述元件功能，“阻抗整形”描述系统层效果。项目不是只证明能量耗散增加，而是量化 K′/K″ 组成随频率变化，并把它与水中力–运动相位、推进波形、涡结构和任务级加速联系起来。核心贡献是利用频率选择性的材料耗散去被动调整耦合系统的相位响应。
